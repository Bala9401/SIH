About the System

Methodology, Architecture, and Data Sources

Methodology

1. Image Classification (CNN)

The system utilizes a Convolutional Neural Network (CNN) based on MobileNetV2 architecture, pre-trained on ImageNet and fine-tuned to classify the satellite product type. It does not identify cyclone names or estimate intensity from visual appearance.

2. Track Forecasting (LSTM)

A Long Short-Term Memory (LSTM) recurrent neural network handles the time-series forecasting. It ingests historical best-track data (latitude, longitude, wind, pressure) over past timesteps to predict future spatial positions and intensity up to 48 hours in advance.

3. Risk Assessment Engine

A rule-based expert system fuses the deep learning outputs (classification and track predictions) to calculate a comprehensive Risk Score (0-100). It categorizes the threat level and triggers specific actionable recommendations for disaster management authorities.

Architecture Pipeline

[ Satellite Image ] + [ Historical Track Data ] | | v v [ CNN MobileNetV2 ] [ LSTM Network ] | | v v [ Intensity Class ] [ Predicted Lat/Lon ] \ / \ / \ / v v [ Risk Assessment Engine ] | v [ Web Dashboard & Alerts ]

Tech Stack

  • Backend: Python, Flask, REST API
  • ML/AI: TensorFlow, Keras, Scikit-learn
  • Frontend: HTML5, Bootstrap 5, JS
  • Visualization: Chart.js, Leaflet.js

Datasets

  • Imagery: INSAT-3D Thermal IR images
  • Track Data: IBTrACS North Indian Ocean basin data
  • Preprocessing: Normalized & scaled historical tracks

Limitations & Disclaimer

This system is a prototype developed specifically for the Smart India Hackathon (SIH). The models are trained on limited historical datasets and are designed to demonstrate the feasibility of AI in disaster management. It is NOT intended for operational meteorological use. The predictions and risk assessments generated should not be relied upon for life-safety decisions or official evacuations. Always rely on bulletins issued by the India Meteorological Department (IMD) or relevant national weather agencies.
